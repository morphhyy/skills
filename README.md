# skills

Claude Code skills.

| Skill | What it does |
|---|---|
| [live-stream-clipper](live-stream-clipper/SKILL.md) | Clip Twitch/YouTube live streams on chat-spike hype moments into vertical captioned Shorts, with optional YouTube upload |

## Install

Copy a skill folder into `~/.claude/skills/` (all projects) or `<project>/.claude/skills/` (one project).

Credentials (YouTube OAuth client, token, cookies) live in `~/.config/live-clipper/` and are never part of this repo.
